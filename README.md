
# SMS Spam Detection using Machine Learning

## Project Overview
This project predicts whether an SMS message is Spam or Not Spam using Machine Learning.

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Matplotlib
- Seaborn

## Project Workflow
1. Load the SMS dataset.
2. Convert messages into numerical features.
3. Train the Naive Bayes model.
4. Evaluate model performance.
5. Predict Spam or Not Spam.
6. Visualize results using a confusion matrix.

## How to Run
Open the notebook in Google Colab and run each cell in order.

## Dataset
SMS spam dataset loaded from a public GitHub-hosted TSV file.
